# AI Prompt Input Output

This Python script simulates a basic AI tool's input validation and output generation. It demonstrates how an AI tool might check incoming data formats and content, and what kind of structured or unstructured responses it can return.

## Language

`python`

## How to Run

Save the code as `ai_io_demo.py` and run it from your terminal using: `python ai_io_demo.py`
